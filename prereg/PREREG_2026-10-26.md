# Pre-specified analysis plan — converged-budget and entity-disjoint evaluation

**Date fixed:** 2026-10-26 (before any run described here was started)
**Commit this file to version control before launching any run; the commit timestamp is the record.**

## 1. Scope

This plan covers three analyses for the paper "Quality Reweighting and Auxiliary Triplet Loss for Frozen-Encoder Person–Job Fit":

- **E4** — re-analysis of the existing 10-epoch predictions (no new training).
- **E1** — converged-budget 2×2 evaluation on the existing pair-overlap split (**primary analysis**).
- **E2** — converged-budget evaluation on new user-disjoint and job-disjoint splits (secondary).

Earlier experiments (including the former "B_FULL" matrix) are not used, pooled, or reported.

## 3. Estimands

With Ā_c the seed-mean pooled test ROC-AUC of cell c:

- W = ½[(Ā₊W − Ā_Base) + (Ā₊W₊T − Ā₊T)] (reweighting main effect)
- T = ½[(Ā₊T − Ā_Base) + (Ā₊W₊T − Ā₊W)] (triplet main effect)
- I = (Ā₊W₊T − Ā₊T) − (Ā₊W − Ā_Base) (interaction)
- WT = Ā₊W₊T − Ā_Base

**Primary analysis:** W, T, and I from E1. Everything else is secondary and descriptive.

## 4. Uncertainty

Two-stage percentile bootstrap, B = 10,000, RNG seed 20261026:

1. Resample training seeds with replacement; a resampled seed carries all four cells.
2. Resample test users with replacement, carrying all of their test pairs.
3. Recompute the per-seed pooled AUC on the resampled pairs, average over the resampled seeds, and compute the estimands.

Report 95% percentile intervals. No equivalence margin is declared. An interval that covers zero is reported as the range of effects compatible with the data, not as evidence of no effect. Job-cluster resampling is reported as a sensitivity analysis only.

## 5. Reporting rules

- All runs are reported. No seed, run, or cell is dropped, replaced, or re-run except under the censoring rule above.
- The test set is never used for any choice (λ, epochs, thresholds, hyperparameters, baselines).
- Any deviation from this plan is listed in the results report with its reason.
